## 简介

LightPic 是一款简洁、轻量、完全离线的 macOS 批量图片缩放与压缩工具。

无需复杂的编辑流程，只需拖入图片、设置尺寸与画质，然后选择输出文件夹即可导出。适合发送图片、上传网站或节省存储空间。

所有图片均在本机处理，不会上传到网络，也不会修改原图。

## 主要功能

- 批量导入 JPEG、HEIC、PNG 和 TIFF 图片
- 使用预设尺寸或自定义宽高进行缩放
- 保持原图比例并避免放大小尺寸照片
- 支持导出为 JPEG、HEIC 和 PNG
- 调整 JPEG/HEIC 输出画质
- 设置目标文件大小
- 导出所选照片或全部照片
- 移除所选照片或清空列表
- 自动避免覆盖原图和已有文件
- 保留目标格式支持的照片元数据
- 支持简体中文和英文

## 快捷操作

| 操作 | 快捷键 |
|---|---|
| 添加照片 | `Command-O` |
| 连续选择 | `Shift-点击` |
| 多项选择 | `Command-点击` |
| 全选照片 | `Command-A` |
| 移除所选照片 | `Delete` |
| 全部导出 | `Command-Return` |

## 系统要求

- macOS 13.0 或更高版本
- Intel 或 Apple Silicon Mac

## 隐私

LightPic 完全在本机运行，不需要网络连接，不会上传、收集或修改原始图片。

## English

LightPic is a lightweight, fully offline batch image resizer and compressor for macOS.

Import your images, choose the dimensions and quality settings, select an output folder, and export. All processing happens locally on your Mac. Images are never uploaded, and original files are never modified.

### Features

- Batch import JPEG, HEIC, PNG, and TIFF images
- Resize using presets or custom dimensions
- Export as JPEG, HEIC, or PNG
- Adjustable JPEG/HEIC output quality
- Optional target file-size limit
- Export selected photos or the entire list
- Shift-click, Command-click, and Command-A selection
- Prevents overwriting original and existing files
- Preserves metadata supported by the output format
- Simplified Chinese and English interface
- Supports Intel and Apple Silicon Macs
- Requires macOS 13.0 or later
