# LightPic

> A lightweight offline batch image resizer for macOS.

一款简洁、离线运行的 macOS 批量图片缩放与压缩工具。

LightPic 专注于快速批量缩放和压缩图片。无需复杂的编辑流程，只需拖入图片、设置尺寸并导出。

LightPic 轻量、简单、完全离线，适合发送图片、上传网站或节省存储空间。

## 主要功能

- 批量导入 JPEG、HEIC、PNG 和 TIFF 图片
- 按预设尺寸或自定义宽高缩放
- 支持导出为 JPEG、HEIC 和 PNG
- 调整 JPEG/HEIC 输出画质
- 设置目标文件体积
- 自动避免覆盖原图和已有文件
- 保留目标格式支持的照片元数据
- 支持简体中文和英文
- 支持 Intel 和 Apple 芯片 Mac

## 系统要求

- macOS 13.0 或更高版本
- Intel 或 Apple Silicon Mac
